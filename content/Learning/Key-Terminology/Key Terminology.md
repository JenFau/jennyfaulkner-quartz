| Term                                      | Description                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Artificial intelligence (AI)              | A broad field covering systems that perform tasks normally associated with human intelligence, such as classification, prediction, language understanding, image recognition, decision support or content generation.                                                                                                                                                                                              |
| Machine learning (ML)                     | A branch of AI where systems learn patterns from data rather than being explicitly programmed with every rule.                                                                                                                                                                                                                                                                                                     |
| Deep learning                             | A type of machine learning using multi-layered neural networks, especially useful for language, images, speech and complex pattern recognition.                                                                                                                                                                                                                                                                    |
| Neural network                            | A computational model inspired loosely by the structure of the brain, made up of connected nodes that learn patterns from data.                                                                                                                                                                                                                                                                                    |
| Model                                     | The trained AI system that takes an input and produces an output, such as a prediction, classification, recommendation or generated response.                                                                                                                                                                                                                                                                      |
| Algorithm                                 | A defined set of instructions or rules used to process data and produce an output. In AI, algorithms are used to train models or make decisions.                                                                                                                                                                                                                                                                   |
| Training                                  | The process of teaching a model by exposing it to data and adjusting its internal parameters so it performs better on a task.                                                                                                                                                                                                                                                                                      |
| Inference                                 | The use of a trained model to produce an output from a new input. In everyday terms, this is what happens when a user asks a model a question.                                                                                                                                                                                                                                                                     |
| [[Parameters]]                            | The internal values learned by a model during training. They shape how the model responds, predicts or classifies.                                                                                                                                                                                                                                                                                                 |
| Weights                                   | A specific type of parameter that determines how strongly one signal influences another inside a model.                                                                                                                                                                                                                                                                                                            |
| Foundation model                          | A large model trained on broad data that can be adapted to many different tasks, often through prompting, fine-tuning or RAG.                                                                                                                                                                                                                                                                                      |
| Large language model (LLM)                | A model trained on large volumes of text and other data to understand, generate, summarise, classify or transform language. IBM describes LLMs as deep learning models commonly built on transformer architecture. ([IBM](https://www.ibm.com/think/topics/large-language-models?utm_source=chatgpt.com "What Are Large Language Models (LLMs)?"))                                                                 |
| Generative AI                             | AI that creates new content, such as text, images, audio, video, code or synthetic data, based on patterns learned during training.                                                                                                                                                                                                                                                                                |
| Predictive AI                             | AI used to forecast, classify or recommend outcomes, such as predicting churn, detecting fraud or estimating demand.                                                                                                                                                                                                                                                                                               |
| Transformer                               | A neural network architecture particularly important in modern language models. It uses attention mechanisms to handle relationships between tokens in a sequence.                                                                                                                                                                                                                                                 |
| Attention mechanism                       | A technique that helps a model weigh which parts of the input are most relevant when producing an output.                                                                                                                                                                                                                                                                                                          |
| [[Tokens]]                                | A chunk of text processed by a language model. A token may be a word, part of a word, punctuation mark or other text fragment.                                                                                                                                                                                                                                                                                     |
| Context window                            | The amount of information a model can consider at once, including the user’s prompt, previous conversation and retrieved material.                                                                                                                                                                                                                                                                                 |
| Prompt                                    | The instruction or input given to an AI model. A prompt can include a question, context, examples, constraints and desired output format.                                                                                                                                                                                                                                                                          |
| Prompt engineering                        | The practice of designing prompts to get more accurate, useful, structured or reliable outputs from an AI system.                                                                                                                                                                                                                                                                                                  |
| System prompt                             | A higher-level instruction that shapes the model’s behaviour, role, tone, boundaries and task priorities.                                                                                                                                                                                                                                                                                                          |
| Few-shot prompting                        | Giving the model a few examples of the desired input and output pattern before asking it to perform the task.                                                                                                                                                                                                                                                                                                      |
| Chain-of-thought prompting                | A prompting approach that encourages step-by-step reasoning. In business use, it is often safer to ask for a concise rationale rather than exposing hidden reasoning.                                                                                                                                                                                                                                              |
| Hallucination                             | A confident but incorrect or unsupported AI output. For business use, this is one of the goblins under the floorboards – often invisible until something creaks.                                                                                                                                                                                                                                                   |
| Grounding                                 | Connecting AI outputs to reliable source material, data or documents so responses are less dependent on the model’s internal training alone.                                                                                                                                                                                                                                                                       |
| Retrieval-augmented generation (RAG)      | An approach where the system retrieves relevant external information, adds it to the prompt, and then asks the model to generate an answer. Google Cloud describes the RAG flow as retrieve, augment and generate. ([Google Cloud Documentation](https://docs.cloud.google.com/docs/generative-ai/glossary?utm_source=chatgpt.com "Generative AI glossary"))                                                       |
| Embedding                                 | A numerical representation of text, images or other data that captures meaning in a form a machine can compare and search. IBM describes vector embeddings as arrays of numbers representing data points. ([IBM](https://www.ibm.com/think/topics/vector-embedding?utm_source=chatgpt.com "What is Vector Embedding? | IBM"))                                                                                     |
| Vector database                           | A database designed to store and search embeddings, often used in semantic search and RAG systems.                                                                                                                                                                                                                                                                                                                 |
| Semantic search                           | Search based on meaning rather than exact keyword matching. Useful when users ask questions in natural language.                                                                                                                                                                                                                                                                                                   |
| Fine-tuning                               | Further training a model on specific examples so it performs better for a particular task, style or domain.                                                                                                                                                                                                                                                                                                        |
| Supervised fine-tuning                    | Fine-tuning using labelled input-output examples, such as examples of customer messages and the correct category. Google Cloud distinguishes this from RAG and prompt engineering as a way of adapting models. ([Google Cloud](https://cloud.google.com/blog/products/ai-machine-learning/to-tune-or-not-to-tune-a-guide-to-leveraging-your-data-with-llms?utm_source=chatgpt.com "RAG vs. Fine-tuning and more")) |
| Reinforcement learning                    | A training method where a model learns through rewards or feedback. It is often discussed in relation to model alignment and behaviour shaping.                                                                                                                                                                                                                                                                    |
| RLHF                                      | Reinforcement Learning from Human Feedback. A technique where human preferences are used to help steer model behaviour.                                                                                                                                                                                                                                                                                            |
| Distillation                              | Creating a smaller model that imitates a larger model, often to reduce cost, latency or deployment complexity.                                                                                                                                                                                                                                                                                                     |
| Multimodal AI                             | AI that can work across more than one type of input or output, such as text, images, audio, video or documents.                                                                                                                                                                                                                                                                                                    |
| Agent                                     | An AI system designed to pursue a goal by planning, using tools, calling APIs, retrieving information or taking actions across steps.                                                                                                                                                                                                                                                                              |
| Tool use                                  | The ability of an AI system to call external tools, such as search, databases, calculators, calendars, email or business systems.                                                                                                                                                                                                                                                                                  |
| Workflow automation                       | The use of AI and/or software rules to trigger, route, transform or complete business tasks across systems.                                                                                                                                                                                                                                                                                                        |
| Orchestration                             | The coordination layer that manages multiple tools, models, steps, agents or workflows.                                                                                                                                                                                                                                                                                                                            |
| API                                       | Application Programming Interface. A structured way for one system to communicate with another, often essential for AI-enabled business workflows.                                                                                                                                                                                                                                                                 |
| Model Context Protocol (MCP)              | A protocol used to connect AI systems to tools, data sources and external services in a standardised way. Useful to understand when discussing agentic workflows.                                                                                                                                                                                                                                                  |
| AI agent framework                        | A development framework used to build agents, manage tools, memory, planning and workflow logic. Examples include LangGraph-style or orchestration-based approaches.                                                                                                                                                                                                                                               |
| Memory                                    | Information retained or retrieved by an AI system to support continuity, personalisation or context-aware responses.                                                                                                                                                                                                                                                                                               |
| Guardrails                                | Rules, checks or constraints designed to keep AI outputs safe, compliant, relevant and within acceptable boundaries.                                                                                                                                                                                                                                                                                               |
| Human in the loop                         | A control model where humans review, approve, correct or intervene in AI-assisted processes. Important for higher-risk workflows.                                                                                                                                                                                                                                                                                  |
| Explainable AI (XAI)                      | Techniques that help users understand why an AI system produced a particular output. NIST includes explainability as part of managing generative AI risks. ([NIST Publications](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf?utm_source=chatgpt.com "Artificial Intelligence Risk Management Framework"))                                                                                                |
| Interpretability                          | The degree to which a person can understand how a model works or why it reached a conclusion.                                                                                                                                                                                                                                                                                                                      |
| Transparency                              | The extent to which users and stakeholders can understand how an AI system is used, what data it relies on and what its limitations are.                                                                                                                                                                                                                                                                           |
| Bias                                      | A pattern of unfair, skewed or systematically inaccurate outputs, often caused by training data, design choices or deployment context.                                                                                                                                                                                                                                                                             |
| Fairness                                  | The principle that AI systems should avoid unjustified disadvantage or discrimination across people, groups or contexts.                                                                                                                                                                                                                                                                                           |
| Alignment                                 | The effort to make AI systems behave in ways consistent with human goals, values, safety expectations and organisational policies.                                                                                                                                                                                                                                                                                 |
| AI governance                             | The structures, policies, roles and controls used to manage AI responsibly across an organisation.                                                                                                                                                                                                                                                                                                                 |
| AI risk management                        | The process of identifying, assessing, mitigating and monitoring risks from AI systems. NIST’s AI Risk Management Framework is a major reference point for this area. ([NIST Publications](https://nvlpubs.nist.gov/nistpubs/ai/nist.ai.100-1.pdf?utm_source=chatgpt.com "Artificial Intelligence Risk Management Framework (AI RMF 1.0)"))                                                                        |
| Model evaluation                          | Testing how well a model performs against defined criteria, such as accuracy, robustness, helpfulness, safety or business usefulness.                                                                                                                                                                                                                                                                              |
| Benchmark                                 | A standard test or dataset used to compare model performance. Benchmarks are useful, but may not reflect real business conditions.                                                                                                                                                                                                                                                                                 |
| Accuracy                                  | How often a model produces the correct output. In business use, this needs to be defined carefully by task.                                                                                                                                                                                                                                                                                                        |
| Precision                                 | Of the items the model identified as positive or relevant, the proportion that were actually correct.                                                                                                                                                                                                                                                                                                              |
| Recall                                    | Of all the relevant items that existed, the proportion the model successfully found.                                                                                                                                                                                                                                                                                                                               |
| F1 score                                  | A metric that balances precision and recall, useful when both false positives and false negatives matter.                                                                                                                                                                                                                                                                                                          |
| Latency                                   | The time taken for an AI system to respond. Important for user experience and operational workflows.                                                                                                                                                                                                                                                                                                               |
| Throughput                                | How much work an AI system can process in a given time. Important for scaling.                                                                                                                                                                                                                                                                                                                                     |
| Cost per token                            | The cost of processing input and output tokens when using many commercial LLM APIs.                                                                                                                                                                                                                                                                                                                                |
| Data leakage                              | When sensitive, private or unintended information is exposed through model training, prompts, outputs, logs or integrations.                                                                                                                                                                                                                                                                                       |
| Data residency                            | Where data is stored or processed geographically. Important for compliance, procurement and enterprise architecture.                                                                                                                                                                                                                                                                                               |
| Personally identifiable information (PII) | Information that can identify a person, such as name, address, email, ID number or other personal data.                                                                                                                                                                                                                                                                                                            |
| Red teaming                               | Testing an AI system by deliberately trying to make it fail, behave unsafely or reveal weaknesses.                                                                                                                                                                                                                                                                                                                 |
| Prompt injection                          | An attack where malicious or hidden instructions try to override the intended behaviour of an AI system.                                                                                                                                                                                                                                                                                                           |
| Jailbreak                                 | A method of trying to bypass model safety rules or restrictions.                                                                                                                                                                                                                                                                                                                                                   |
| Synthetic data                            | Artificially generated data used for testing, training or augmentation, especially where real data is scarce or sensitive.                                                                                                                                                                                                                                                                                         |
| Digital worker                            | A business-friendly term for an automated or AI-enabled system that performs tasks across tools or processes.                                                                                                                                                                                                                                                                                                      |
| Copilot                                   | An AI assistant designed to support a human user rather than act fully independently.                                                                                                                                                                                                                                                                                                                              |
| Autonomous AI                             | AI that can take actions with limited human intervention. In business settings, this requires careful controls.                                                                                                                                                                                                                                                                                                    |
| Use case                                  | A specific business situation where AI could create value, reduce effort, improve quality or support decision-making.                                                                                                                                                                                                                                                                                              |
| Proof of concept (PoC)                    | A small test to see whether an AI idea is technically feasible.                                                                                                                                                                                                                                                                                                                                                    |
| Pilot                                     | A limited real-world trial with users, process context and success measures.                                                                                                                                                                                                                                                                                                                                       |
| Minimum viable product (MVP)              | A working early version of a product with enough features to test value and usability.                                                                                                                                                                                                                                                                                                                             |
| ROI                                       | Return on investment. In AI work, this usually considers time saved, cost reduced, revenue increased, risk reduced or quality improved.                                                                                                                                                                                                                                                                            |
| Adoption                                  | The extent to which users actually use the AI solution in practice. A forgotten AI tool is just expensive wallpaper.                                                                                                                                                                                                                                                                                               |
| Change management                         | The people-side work needed to introduce AI successfully, including communication, training, process redesign and stakeholder engagement.                                                                                                                                                                                                                                                                          |
