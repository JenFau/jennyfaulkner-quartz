Obsidian can be used with Claude Desktop via a MCP.  [Zen van Riel](https://youtu.be/VeTnndXyJQI?si=ZEr9kWnrTb4eoaW4)  (March 2025) shows one way of setting up Obsidian and Claude Desktop using [this MCP](https://github.com/MarkusPfundstein/mcp-obsidian) that allows for writing to the vault as well as reading it.

Claude code can be used directly with the Obsidian vault. This is an advantage of Obsidian, which uses markdown files on your computer, over applications such as Notion or Roam which store information in a proprietary format in the cloud and require MCP servers to connect. [ICOR with Tom](https://www.youtube.com/live/UrRoa_J0yDQ?si=wAdCRAEjUN5JqN2Z) echoes this point, and also claims that using Obsidian with Claude code shifts the focus away from manual set up (which may include setting up plug-ins, deciding on a system, etc), which reduces what he calls the 'Obsidian Tax'.
\*\*
[Vicky Zhao](https://youtu.be/FtJYJF8QodM?si=JBmIJPRn3SvC0QuW) (Feb 2026) uses Claude Code with Obsidian. Her main focus in this video is using her Obsidian vault as context to her AI work, to improve the quality of her AI results. This is an interesting approach which is slightly different from either using Obsidian simply to capture the results of AI conversations, or to use AI to find / summarise notes in the vault.

[Cole Medin](https://youtu.be/jYMhDEzNAN0?si=klgtThVbWUgH9dfg) (Jan 2026) goes a step further and uses agents with Claude Code and Obsidian, drawing on Claude Skills. His set automatically His set up automatically searches AI news and generates ideas based on the research, pulls in information from other tools such as Gmail and Calendar, and generates content.

[Brad AI & Automation](https://youtu.be/wdc2tI_TGtM?si=Dm8MgVULjndt1uad) takes a more operational approach by treating his Obsidian vault as a structured system of record for everyday work. Notably, he uses separate Claude Code instances or specialist “AI co-workers,” allowing multiple pieces of work to run in parallel. The emphasis is less on prompting and more on structuring knowledge and tasks so that Claude can operate over them consistently and traceably.

The ability for Claude Code to interact so effectively with an Obsidian vault has led [Vibes DIY](https://youtu.be/1U32hZYxfcY?si=QziFmzRFr5FPphQ6) to use it as a life management system, not just as a topic-based knowledge management system. Most of his notes are daily notes, health logs, meetings notes and reflections. Claude reads his recent life data, applies personal frameworks and produces strategic advice.

[Artem Zhutov](https://youtu.be/RDoTY4_xh0s?si=yDZQfKgMSYnEbKAm) (Feb 2026) also uses Claude with Obsidian, with the addition of QMD as a search option.

[Greg Isenberg](https://youtu.be/6MBq1paspVU?si=AruuajV4fYilULtu) (Feb 2026) gives a thoughtful breakdown of using Claude with Obsidian, including some sensible boundaries about not automating too much.
